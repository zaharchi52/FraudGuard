# FraudGuard — Dart / Flutter Web

Браузерная версия FraudGuard на Dart + Flutter. Она повторяет скоринг C++/Kotlin и предоставляет ту же демонстрационную ленту, очередь REVIEW, ручные решения оператора и CSV-отчёты.

> Важно: браузерная версия работает локально в открытой вкладке. CSV-файлы выбираются через системный диалог браузера и не отправляются на сервер. Это симулятор для учебного проекта, не банковская система и не обработчик реальных платежей.

## Требования

- Flutter stable, включающий Dart SDK 3.10 или новее.
- Google Chrome или Microsoft Edge.
- VS Code с расширениями Flutter и Dart (рекомендуется).

Проверьте установку из PowerShell:

```powershell
flutter --version
flutter doctor -v
```

## Первый запуск

Из корня репозитория:

```powershell
Set-Location .\dart
flutter pub get
flutter run -d chrome
```

Или из папки `dart` запустите `run-web.bat`.

При первом запуске Flutter скачает пакеты `decimal` и `file_picker`. Устройство `Chrome` можно заменить на `Edge`:

```powershell
flutter run -d edge
```

## Сборка статического Web-приложения

```powershell
flutter build web --release
```

Готовая статическая сборка появится в `dart/build/web`. Её можно развернуть на GitHub Pages, GitLab Pages или любом статическом веб-хостинге. Для GitHub Pages нужно настроить базовый URL (`--base-href`) согласно имени репозитория.

## Возможности интерфейса

1. Демо-набор `transactions.csv` и `history.csv` загружается автоматически.
2. Можно выбрать собственные CSV-файлы через браузер.
3. Поток воспроизводится постепенно; скорость меняется от 0,3 до 2,5 секунды.
4. Операции `APPROVE` и `BLOCK` получают автоматический статус, `REVIEW` поступают в очередь оператора.
5. Оператор может одобрить или отклонить транзакцию. Рекомендация движка и окончательное решение оператора хранятся раздельно.
6. Можно скачать `results.csv`, `alerts.csv`, `errors.csv` и `operator-decisions.csv`.
7. Кнопка сверки сравнивает результат Dart с эталонным `data/expected-results.csv`.

## Тестирование

```powershell
flutter test
flutter analyze
```

Проверяются совпадения с эталонными результатами, ошибки в CSV, cold-start и граничные пороги 29/30/59/60.

## Ограничения браузерной версии

Браузер не может запускать локальные `.exe`/процессы пользователя напрямую из-за модели безопасности браузера. Поэтому Dart Web выполняет ту же бизнес-логику самостоятельно и сверяется с общим эталонным CSV. Для запуска C++-исполняемого файла используйте CLI или Kotlin Desktop, где уже предусмотрена кнопка пакетного запуска C++.

## Зависимости

- `decimal` — десятичная арифметика без ошибок двоичного `double`.
- `file_picker` — выбор локальных CSV и загрузка сформированных отчётов в браузере.
