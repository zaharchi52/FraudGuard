# FraudGuard Kotlin — настольное приложение

Kotlin-версия повторяет антифрод-логику C++ и предоставляет Swing-интерфейс с имитацией ленты, очередью `REVIEW` и отдельным журналом решений оператора. Все операции учебные, данные синтетические.

## Требования

- JDK 17 или новее.
- Gradle Wrapper из папки проекта (`gradlew.bat`).
- Доступ к Maven Central при первом запуске для загрузки зависимостей.

## Запуск GUI

Из корня репозитория:

```powershell
Set-Location .\kotlin
.\gradlew.bat run
```

## Запуск тестов

```powershell
Set-Location .\kotlin
.\gradlew.bat clean test --rerun-tasks
```

HTML-отчёт Gradle создаётся в `kotlin/build/reports/tests/test/index.html`.

В проекте используется JUnit 5 и утверждения из `kotlin.test`. Kotest не подключён: в требованиях JUnit и Kotest указаны как альтернативы.

## Работа с интерфейсом

1. Выберите файл новых транзакций и необязательный файл истории.
2. Нажмите **Старт ленты**.
3. Обычные операции получают автоматическую рекомендацию, а `REVIEW` появляется в очереди.
4. Выберите операцию и нажмите **Одобрить выбранную** или **Отклонить выбранную**.
5. Исходная рекомендация движка сохраняется отдельно от решения оператора.

Кнопка **Запустить C++ batch** запускает собранный C++ executable, если он доступен.

## Отчёты

- `results.csv` — результаты скоринга.
- `alerts.csv` — транзакции `REVIEW` и `BLOCK`.
- `errors.csv` — ошибки чтения и валидации.
- `operator-decisions.csv` — решения оператора.
