# Данные

- `history.csv` — синтетическая история двух клиентов.
- `transactions.csv` — девять валидных входных транзакций для сценариев `APPROVE`, `REVIEW`, `BLOCK` и проверки частотного правила.
- `transactions_invalid.csv` — отдельный набор для проверки валидации и продолжения обработки после ошибки.
- `expected-results.csv` — эталонный скор, решение, факторы и статус профиля для валидного набора `transactions.csv`.

Эталонные результаты рассчитаны по `docs/requirements.md`. Если меняется правило или статистическая конвенция, обновить нужно и требования, и тесты, и этот файл.
