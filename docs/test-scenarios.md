# Приёмочные сценарии и тестовые данные

Эталонные входные файлы находятся в `data/`. Ожидаемые результаты для валидных строк — в `data/expected-results.csv`.

| Сценарий | Проверка |
|---|---|
| Обычная транзакция C001 | Нет сработавших правил, `APPROVE`. |
| Сумма выше P95, но меньше 5× медианы | Только `UNUSUAL_AMOUNT`; `HIGH_AMOUNT` не срабатывает. |
| Сумма не менее 5× медианы | `HIGH_AMOUNT`, скор 30 и `REVIEW`. |
| Большая сумма + новая страна, устройство, категория | Факторы суммируются, итоговый скор не ниже 60 и `BLOCK`. |
| Пятая операция за 5 минут | `HIGH_VELOCITY` срабатывает на пятой операции. |
| Новые признаки на пятой операции | Дополнительные факторы поднимают скор до `BLOCK`. |
| Отрицательная сумма / некорректная дата / пустое поле | Ошибка строки; последующие строки обрабатываются. |
| Скора 29/30/59/60/100 | Проверить граничное назначение решений. |
| Сумма факторов > 100 | Итог ограничивается 100. |
