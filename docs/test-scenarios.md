# Приёмочные сценарии и тестовые данные

Основные эталонные файлы находятся в `data/`; расширенный межъязыковой набор — в `data/conformance/`.

| Сценарий | Проверка |
|---|---|
| Обычная транзакция | Нет сработавших правил, `APPROVE`. |
| Сумма ровно на P95 | `UNUSUAL_AMOUNT` не срабатывает; условие строгое `>`. |
| Сумма выше P95, но ниже 5× медианы | Только `UNUSUAL_AMOUNT`, +15. |
| Сумма ровно 5× медиану | `HIGH_AMOUNT`, +30. |
| Новая страна, устройство и категория | Три отдельных фактора при READY-профиле. |
| Пятая операция в окне 10 минут | Срабатывает `HIGH_VELOCITY`; нижняя граница окна включительная. |
| Операция позже окна более чем на 10 минут | Предыдущие события вне окна не учитываются. |
| История 0 / 1–4 / 5+ | COLD_START / LIMITED_HISTORY / READY. |
| Профиль другого клиента или валюты | Не смешивать статистику и признаки. |
| Скор 29/30/59/60/100 | APPROVE/REVIEW/BLOCK по точным границам. |
| Сумма факторов > 100 | Итог ограничивается 100. |
| Дубликат ID / отрицательная сумма / дата без часового пояса / пустое поле | Записывается ошибка; следующие валидные строки обрабатываются. |
| CSV quoted comma / escaped quote / BOM / CRLF | Корректная запись читается; произвольный суффикс после закрывающей кавычки отклоняется. |
| REVIEW workflow | Одно операторское решение; повторно разрешить/отклонить уже решённую операцию нельзя. |

Для детального покрытия см. [`test-plan.md`](test-plan.md), [`cross-language-conformance.md`](cross-language-conformance.md) и [`manual-acceptance-tests.md`](manual-acceptance-tests.md).
