# Отчёт о дефектах FraudGuard

## Журнал найденных дефектов

| ID | Серьёзность | Компонент | Описание | Исправление | Статус |
|---|---|---|---|---|---|
| FG-001 | Medium | C++ tests | Smoke tests опирались на `assert()`, который отключается макросом `NDEBUG` в Release. Из-за этого CTest мог завершиться успешно, не выполняя проверок. | Заменено на явные runtime-проверки с ненулевым кодом завершения при ошибке; добавлена пакетная сверка с golden CSV и проверка восстановления после ошибок строк. | FIXED; повторно проверено в Release |
| FG-002 | Medium | Kotlin CSV | Парсер принимал произвольные символы после закрывающей кавычки (`"value"suffix`), тогда как C++ отклонял такой CSV. Это создавало риск разных результатов между реализациями. | Добавлено состояние закрытой кавычки; разрешены только разделитель, конец строки или пробелы/табуляция, как в C++. | FIXED; проверено локальным Kotlin production harness |
| FG-003 | Medium | Dart CSV | Аналогично Kotlin, парсер принимал символы после закрывающей кавычки, что нарушало межъязыковую согласованность. | Добавлено состояние закрытой кавычки и согласованная ошибка разбора. | FIXED; автоматический Flutter test добавлен, ожидает локального прогона |

## Найденные дефекты, ожидающие проверки пользователя

Пока не зарегистрированы. Если пользовательский запуск выявит проблему в MSVC/Windows, Gradle/JUnit или Flutter/Chrome, добавить её сюда с шагами воспроизведения и версией инструментов.

## Правило закрытия дефекта

Дефект можно перевести в `Closed` только после повторного запуска теста, который воспроизводил проблему, и регрессионной проверки связанного сценария. Наличие коммита само по себе не означает, что дефект закрыт.
