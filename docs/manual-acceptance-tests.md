# Ручные приёмочные тесты GUI

Проводить на Windows 10/11 в VS Code. Для Kotlin нужен JDK 17+; для Dart Web — Flutter stable и Chrome/Edge. Использовать только синтетические файлы из `data/`.

| ID | Компонент | Действия | Ожидаемый результат |
|---|---|---|---|
| UI-01 | Kotlin + Dart | Открыть приложение | Окно / web-панель загружается без исключения и показывает демонстрационный режим |
| UI-02 | Kotlin + Dart | Загрузить `data/transactions.csv` и `data/history.csv` | Оба файла отображаются как выбранные; ошибок схемы нет |
| UI-03 | Kotlin + Dart | Нажать Start | Транзакции появляются постепенно; счётчики меняются |
| UI-04 | Kotlin + Dart | Нажать Pause во время ленты | Новые строки перестают появляться; уже выведенные строки остаются |
| UI-05 | Kotlin + Dart | Нажать Resume/Start после паузы | Лента продолжается с места остановки, строки не дублируются |
| UI-06 | Kotlin + Dart | Выбрать REVIEW в очереди и открыть детали | Видны score, факторы, клиент, сумма и исходная рекомендация движка |
| UI-07 | Kotlin + Dart | Одобрить REVIEW | Статус становится `APPROVED_BY_OPERATOR`; повторное решение недоступно |
| UI-08 | Kotlin + Dart | Отклонить другой REVIEW | Статус становится `REJECTED_BY_OPERATOR`; повторное решение недоступно |
| UI-09 | Kotlin + Dart | Проверить APPROVE и BLOCK | Автоматические решения не появляются в очереди ручной проверки |
| UI-10 | Kotlin + Dart | Сбросить ленту и запустить повторно | Счётчики, очередь и текущая последовательность сброшены |
| UI-11 | Kotlin + Dart | Загрузить `data/transactions_invalid.csv` | Корректная строка после дефектных обрабатывается; причины ошибок видны/экспортируются |
| UI-12 | Kotlin + Dart | Отключить/не загружать историю и запустить | Профили клиентов имеют COLD_START; profile-only факторы не начисляются |
| UI-13 | Kotlin + Dart | Экспортировать results / alerts / errors | Браузер скачивает CSV; Kotlin записывает CSV в выбранную output-папку |
| UI-14 | Kotlin + Dart | Экспортировать operator decisions после UI-07/UI-08 | В отчёте отдельно записаны `engine_decision` и `operator_decision` |
| UI-15 | Kotlin | Нажать «Запустить C++ batch» после сборки C++ | Открывается пакетный C++-анализ; в output появляется `cpp-batch` с тремя CSV |
| UI-16 | Dart Web | Выбрать собственный CSV через браузерный picker | Содержимое считывается локально; файл не загружается на сервер |
| UI-17 | Dart Web | Скачать CSV-отчёт | Файл появляется в загрузках браузера и открывается как корректный CSV |
| UI-18 | Kotlin + Dart | Изменить скорость ленты | Частота появления строк соответствует настройке |

## Что приложить к отчёту

1. Скриншот главного окна Kotlin и браузерной версии Dart.
2. Скриншот/запись работающей ленты.
3. Скриншот выбранной REVIEW-транзакции и результата ручного решения.
4. Фрагменты `operator-decisions.csv` с одобрением и отклонением.
5. Вывод `ctest`, Gradle test, Flutter analyze и Flutter test.

Результат отмечается как `PASS`, `FAIL` или `BLOCKED`. Для `FAIL` создать запись в [`defect-report.md`](defect-report.md). Не отмечать тест пройденным без фактического запуска.
