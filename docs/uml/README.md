# UML-диаграммы FraudGuard

Для учебного задания используйте **три основные диаграммы**:

1. `use-case.puml` — Use Case: акторы и действия пользователя.
2. `class-diagram.puml` — Class: главные сущности и компоненты.
3. `sequence.puml` — Sequence: порядок обработки CSV, скоринга и ручной проверки.

Диаграммы намеренно упрощены: показывают основные части системы, а не каждый вспомогательный метод исходного кода. Для студенческого проекта этого достаточно, если вы можете объяснить каждую сущность и связь.

## Как открыть диаграммы в VS Code

1. Откройте папку `FraudGuard` в VS Code.
2. Установите расширение **PlantUML**.
3. Откройте файл `.puml`.
4. Нажмите `Alt + D` или выберите **PlantUML: Preview Current Diagram**.
5. Для отчёта экспортируйте Preview в PNG или SVG.

Если расширение просит PlantUML server или Graphviz, используйте способ настройки, который предлагает само расширение. Исходники `.puml` обязательно оставьте в репозитории.

## Что сказать на защите

- **Use Case:** аналитик запускает анализ и смотрит алерты; оператор вручную обрабатывает `REVIEW`.
- **Class:** `Transaction` содержит данные операции; `ClientProfile` хранит статистику клиента; `ScoringEngine` выдаёт оценку; `TransactionResult` хранит результат; `ReportWriter` сохраняет файлы.
- **Sequence:** сначала загружаются и проверяются CSV, затем движок считает риск, после чего система показывает результат и сохраняет отчёты. Если есть `REVIEW`, оператор принимает отдельное решение.

Файлы `kotlin-class-diagram.puml`, `kotlin-live-sequence.puml`, `dart-class-diagram.puml` и `dart-live-sequence.puml` — дополнительные технические варианты для команды. Их можно не включать в основной отчёт, чтобы не перегружать студенческую работу.
